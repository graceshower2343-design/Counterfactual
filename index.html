Counterfactual extends the open-source Timesketch forensic timeline platform (Apache-2.0, copyright the Timesketch authors). Event records here use Timesketch-style fields (datetime, message, data_type, source). This page is a self-contained demo: the simulation is a deterministic rule model on prepared data, and "Estimated impact prevented" is a weighted estimate, not a validated probability. Explanations are generated from the structured timeline by rules, with no external AI service.
